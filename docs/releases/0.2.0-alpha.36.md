## Änderungen dieser Ausgabe

- Korrigiert die Lebensdauer von Schattenkameras bei Szenenwechseln mit D3D11.
- Ergänzt eine passive Ping-Messung für den Mac/Wine-Starter; Windows nutzt weiterhin seinen nativen Messweg.
- Mac-Starter mit Einrichtungsassistent für denselben Enhanced-Client und Updatekanal: D3DMetal, angepasster Audiopuffer, Diagnose, Reparatur und kurze Anleitung. CrossOver wird separat benötigt; die Mac-App ist eine noch nicht von Apple notarisierte Alpha-Vorschau.
